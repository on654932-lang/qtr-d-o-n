3 bước dán code vào Google Apps Script (chạy toàn màn hình):
Bước 1: Mở Apps Script & dán code vào file Mã.gs (có sẵn cầu nối lấy giá trực tiếp)
Bước 2: Mở file index.html → xóa chữ cũ → dán code App

Bước 3: Bấm Lưu (Ctrl+S) → Triển khai → Quản lý các tùy chọn triển khai → bấm Chỉnh sửa (✏️) → đổi mục Phiên bản sang Phiên bản mới → bấm Triển khai.
